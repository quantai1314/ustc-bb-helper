# 本地 UI 预览

安装 Node.js 后，在仓库根目录运行：

```sh
node dev/preview.mjs
```

打开 <http://127.0.0.1:4173>。无需安装依赖、油猴扩展或登录学校账号，服务仅监听本机，所有课程、作业和成绩都是虚构数据，不会访问学校平台。按 `Ctrl+C` 停止服务。

页面直接加载仓库中的 `USTC-BB-Helper.user.js`，修改后刷新即可看到效果。「查看原始页面」可对比不加载脚本的基线。模拟 DOM 只覆盖脚本所需的常见 Blackboard 结构，不代替真实平台验证。

## 验证场景

- 门户包含 6 门课程：概率论 1 项未交，线性代数和人工智能已交齐，学术交流无作业区，物理实验模拟课程查询错误。数据结构有 2 项未交，但其中一项其他作业查询失败，因此课程显示「查询错误」并提示统计可能不完整。检查排序、数量和直达作业区链接。
- 数据结构作业区包含未提交、已提交、已评分（96 / 100）、查询错误和预先忽略的选做作业，以及较长中文标题。
- 作业列表末尾的「课程资料」是非作业条目，切换任意作业筛选后应仍然可见。
- 点击作业状态切换忽略，再回主页，检查未提交数同步；刷新作业页，检查忽略状态持久化。
- 用 Tab、Enter 和空格操作状态按钮；在窄窗口和浏览器缩放后检查标题、徽章和概览是否溢出。
- 首次打开会初始化一项忽略记录；之后保留本机演示状态。「重置演示数据」只清除此预览源的 `ustc-bb-*` 数据，恢复默认样例并清空门户缓存，不影响学校域名上的数据。
- 门户第二次加载应使用当日缓存。可点击「重置演示数据」重新观察加载过程。模拟请求立即响应，必要时可在开发者工具中限制网络速度。

预览服务只用于本地开发，请勿部署到公网。
