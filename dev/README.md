# 本地 UI 预览

安装 Node.js 后，在仓库根目录运行：

```sh
node dev/preview.mjs
```

打开 <http://127.0.0.1:4173>。无需安装依赖、油猴扩展或登录学校账号，服务仅监听本机，所有课程、作业和成绩都是虚构数据，不会访问学校平台。按 `Ctrl+C` 停止服务。

页面直接加载仓库中的 `USTC-BB-Helper.user.js`，修改后刷新即可看到效果。「查看原始页面」可对比不加载脚本的基线。主页的「查看 260px 窄门户列」或 <http://127.0.0.1:4173/?compact=1> 可在宽浏览器窗口中检查窄课程模块；基线切换保留列宽。视窗宽度小于 650px 时恢复单列布局。

模拟作业列表包含 Blackboard 常见的 `contentList`、`item_icon`、`item clearfix`、标题链接内的 `span` 以及 `details > vtbegenerated` 结构，图标为本地内嵌 SVG，不加载外网资源。「我的成绩」接口另模拟 `grades_wrapper`、标题直接文本或链接、提交活动、评分图标等批量状态结构。它只覆盖常见结构，不代替真实平台验证。

预览默认同时模拟真实 BB 使用的 Prototype 1.7：它会将 `Array.from` 替换成旧版 `$A`，忽略第二个映射参数，也不能将 `Set` 正确转换为数组。这一兼容环境是默认验证条件；只有专门对比原生 API 时才设置 `BB_PREVIEW_PROTOTYPE=0`。

## 验证场景

- 门户包含 7 门课程。清空缓存首次打开时，首页应自动查询并逐步显示数量，无需先进入作业区。概率论有 1 项未提交，线性代数和人工智能已交齐；数据结构有 2 项已查到待提交、1 项查询失败待确认，选做作业预先忽略。学术交流无作业区，物理实验模拟入口查询错误，空作业区显示「作业已交齐」。检查已查到的待交数量、渐进排序和直达作业区链接；有失败或未确认项目时不能误显示已交齐。
- 正常批量查询应从「我的成绩」页面获取待提交、已提交和已评分状态，只为数据结构中在成绩表缺失的错误项单独请求作业页面。线性代数第一项故意使用 `upcoming_item_row`，但带已提交活动和 `needs_grading.png`，仍须识别为已提交。
- 5 门课程带 `CS2502A.02.2026FA:` 一类的示例编号前缀，学术交流课程不带编号，人工智能保留长标题。检查课程名为主行、编号为灰色次行，无编号课程没有空行，长标题和 260px 窄列不横向溢出；主页概览在窄列中保持紧凑。
- 数据结构作业区包含未提交、已提交、已评分（96 / 100）、查询错误和预先忽略的选做作业，以及较长中文标题。
- 作业概览用一排带数字的「全部／待提交／已完成／已忽略」按钮筛选，检查数字随忽略与恢复操作同步更新，窄窗口时允许换行。
- 预览模拟原站作业列表的负外边距（桌面顶部 -20px，窄屏 -12px）。有概览时仅上外边距归零；切换各个筛选后，概览与第一条可见内容之间应保持 16px 间距，不相互覆盖。
- 作业列表末尾的「课程资料」是非作业条目，切换任意作业筛选后应仍然可见。
- 点击独立的「忽略／恢复」按钮切换忽略状态，再回主页，检查未提交数同步；刷新作业页，检查忽略状态持久化。状态标签与标题链接各自显示，点击状态文字不应切换忽略或打开作业。
- 用 Tab、Enter 和空格操作筛选与「忽略／恢复」按钮；在窄窗口、260px 门户列和浏览器缩放后检查标题、编号、状态标签和概览是否溢出。
- 首次打开会初始化一项忽略记录；之后保留本机演示状态。「重置演示数据」只清除此预览源的 `ustc-bb-*` 数据，恢复默认样例并清空门户缓存，不影响学校域名上的数据。
- 重新进入门户时先展示上次统计并提示更新中，随后在后台核验当前状态；不能把当天的缓存当成永久有效。可点击「重置演示数据」重新观察首次加载过程。
- 设置 `BB_PREVIEW_LEGACY_ZERO_CACHE=1` 并重置演示数据，会种入旧版无版本的当日错误零值：概率论缓存为已交齐，但实际有 1 项待交。新版本应忽略这份旧统计并重新查询，最终显示 1 项待交。
- 首页查询获得的单项状态快照与作业区共享：先在首页完成概率论查询，5 分钟内进入该课作业区，检查已有状态可先展示，并明确提示后台核验中；随后通过批量接口更新，不重复打开已由批量结果确认的复查页。忽略／恢复或打开单项作业后，关联快照与计数应失效或同步更新。部分失败记录不能作为完整“已交齐”统计复用。

## 慢请求与回退场景

通过启动服务前设置环境变量切换场景，切换后重启服务并重置演示数据。以下变量可组合，除 Prototype 兼容模拟默认启用外，其余场景默认关闭：

| 环境变量 | 用途与预期 |
| --- | --- |
| `BB_PREVIEW_SLOW_MS=20000` | 仅让单项已提交／已评分复查页慢 20 秒。正常批量查询不应访问这些慢页，首页仍可正常显示已查到的数量。 |
| `BB_PREVIEW_GRADES_OFF=1` | 「我的成绩」接口返回 503，验证自动回退逐项确认。可和慢复查页组合检查其他课程的数量先更新。 |
| `BB_PREVIEW_GRADES_SLOW_MS=20000` | 延迟批量接口，验证请求超时后能回退或明确提示，不能永久卡在查询中。 |
| `BB_PREVIEW_EDGE_CASES=1` | 数据结构前两项使用重复标题；概率论第一项在成绩表标为草稿；人工智能的成绩表显示没有提交历史佐证的人工零分。以上项目应单独确认，最终待交数量仍与默认场景相同。 |
| `BB_PREVIEW_PORT=4174` | 更换本地监听端口。 |
| `BB_PREVIEW_LOG_REQUESTS=1` | 在服务终端输出本地请求，用于核对批量查询、单项回退和缓存是否减少请求。 |
| `BB_PREVIEW_PROTOTYPE=0` | 关闭默认启用的旧版 `Array.from` 覆盖，专门对比原生环境。正常验证应保留默认兼容环境。 |
| `BB_PREVIEW_LEGACY_ZERO_CACHE=1` | 重置演示数据时种入概率论的旧版当日 `u: 0` 缓存，验证升级后重新查询并纠正数量。 |

PowerShell 示例：

```powershell
$env:BB_PREVIEW_SLOW_MS = '20000'
node dev/preview.mjs
```

结束后用 `Remove-Item Env:BB_PREVIEW_SLOW_MS` 清除当前终端中的设置。上面列的是预览验证场景与预期结果，不表示这些组合均已实测。

预览服务只用于本地开发，请勿部署到公网。

## 无依赖回归测试

```sh
node --test dev/regression.test.mjs
```

测试使用 Node 内置 `test` 和 `vm`，直接提取当前用户脚本中的查询函数执行，不启动浏览器、不访问学校平台。隔离上下文复现 BB 的旧版 `Array.from` 覆盖，检查批量任务实际启动、每项回调、重名及批量缺失的单项回退，并检查漏回调和部分失败不会被统计为完整零值。这些测试不代替真实页面的 DOM 和视觉验证。
