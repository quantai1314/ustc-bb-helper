# 本地 UI 预览

安装 Node.js 后，在仓库根目录运行：

```sh
node dev/preview.mjs
```

打开 <http://127.0.0.1:4173>。无需安装依赖、油猴扩展或登录学校账号，服务仅监听本机，所有课程、作业和成绩都是虚构数据，不会访问学校平台。按 `Ctrl+C` 停止服务。

页面直接加载仓库中的 `USTC-BB-Helper.user.js`，修改后刷新即可看到效果。「查看原始页面」可对比不加载脚本的基线。主页的「查看 260px 窄门户列」或 <http://127.0.0.1:4173/?compact=1> 可在宽浏览器窗口中检查窄课程模块；基线切换保留列宽。视窗宽度小于 650px 时恢复单列布局。

模拟作业列表包含 Blackboard 常见的 `contentList`、`item_icon`、`item clearfix`、标题链接内的 `span` 以及 `details > vtbegenerated` 结构，图标为本地内嵌 SVG，不加载外网资源。它只覆盖常见结构，不代替真实平台验证。

## 验证场景

- 门户包含 7 门课程。首次打开时，有作业区且未缓存的课程显示「进入作业区查询」，不请求各作业状态；学术交流无作业区，物理实验模拟入口查询错误。进入一门课的作业区完成查询后再回主页，检查该课显示缓存统计；依次查询后可看到概率论 1 项未交、线性代数和人工智能已交齐。数据结构有一项作业查询失败，因此不写回统计，主页仍显示「进入作业区查询」以便重试；空作业区示例回写「作业已交齐」。检查缓存后的排序、数量和直达作业区链接。
- 5 门课程带 `CS2502A.02.2026FA:` 一类的示例编号前缀，学术交流课程不带编号，人工智能保留长标题。检查课程名为主行、编号为灰色次行，无编号课程没有空行，长标题和 260px 窄列不横向溢出；主页概览在窄列中保持紧凑。
- 数据结构作业区包含未提交、已提交、已评分（96 / 100）、查询错误和预先忽略的选做作业，以及较长中文标题。
- 作业概览用一排带数字的「全部／待提交／已完成／已忽略」按钮筛选，检查数字随忽略与恢复操作同步更新，窄窗口时允许换行。
- 预览模拟原站作业列表的负外边距（桌面顶部 -20px，窄屏 -12px）。有概览时仅上外边距归零；切换各个筛选后，概览与第一条可见内容之间应保持 16px 间距，不相互覆盖。
- 作业列表末尾的「课程资料」是非作业条目，切换任意作业筛选后应仍然可见。
- 点击独立的「忽略／恢复」按钮切换忽略状态，再回主页，检查未提交数同步；刷新作业页，检查忽略状态持久化。状态标签与标题链接各自显示，点击状态文字不应切换忽略或打开作业。
- 用 Tab、Enter 和空格操作筛选与「忽略／恢复」按钮；在窄窗口、260px 门户列和浏览器缩放后检查标题、编号、状态标签和概览是否溢出。
- 首次打开会初始化一项忽略记录；之后保留本机演示状态。「重置演示数据」只清除此预览源的 `ustc-bb-*` 数据，恢复默认样例并清空门户缓存，不影响学校域名上的数据。
- 已查询课程的统计应在门户第二次加载时使用当日缓存，未查询课程仍显示「进入作业区查询」。可点击「重置演示数据」重新观察加载过程。模拟请求默认立即响应；可设置 `BB_PREVIEW_SLOW_MS` 模拟慢复查页，用 `BB_PREVIEW_PORT` 更换端口。

预览服务只用于本地开发，请勿部署到公网。
