# USTC BB 助手 (USTC BB Helper)

为中科大 bb 网络教学平台（Blackboard）增强的油猴脚本。基于 [PRO 的 USTC Helper](https://greasyfork.org/zh-CN/scripts/453530-ustc-helper)（GPL-3.0）的 bb 模块修复并独立而来，**无任何外部依赖**（原脚本因 `@require` 的 GitHub 依赖 404 而整体失效，本脚本已彻底移除此依赖）。

## 功能

- **作业区状态标注**：在作业列表自动标注每个作业的状态徽章 —— 已提交（绿）/ 未提交（红）/ 已评分（蓝，显示分数）/ 查询错误（黄）
- **作业概览与筛选**：一排按钮同时显示各状态数量并提供筛选，减少顶部占用；查询进度、失败提示和筛选空状态单独展示
- **忽略与恢复**：状态徽章旁有独立的「忽略 / 恢复」按钮，忽略后浅灰显示并收起详情；支持 Tab、Enter 和空格操作，忽略记录存于 localStorage，主页未提交数目会同步更新
- **课程概览**：以卡片展示当前课程，紧凑汇总已查到的待交作业和待办课程数量；突出课程名，将标准课程编号放在灰色次行，长标题和窄栏布局自动换行
- **主页自动统计与排序**：首次打开门户主页就自动查询各课未提交作业数，无需先进入作业区；优先从「我的成绩」批量获取状态，只为无法确认的作业查询单项页面。红色「未提交 N」徽章随查询结果更新并降序置顶，「作业已交齐」居中
- **直达作业区**：主页点击课程名称直接进入该课程作业区，不再跳转课程主页（课程主页仍可从课程内左侧菜单进入）
- **主题跟随**：主页「个性化页面」选的主题颜色应用到所有页面（BB 默认只在主页生效）；换主题后打开一次主页即自动更新
- **自动登录**：登录页自动点击「统一身份认证登录」
- **校外自动认证**：`/nginx_auth/` 页面自动点击认证链接

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 从 [Greasyfork](https://greasyfork.org/zh-CN/scripts/600725-ustc-bb-helper) 安装（推荐，可自动更新），或点击安装：[USTC-BB-Helper.user.js](https://github.com/quantai1314/ustc-bb-helper/raw/main/USTC-BB-Helper.user.js)

## 说明

- 仅匹配 `www.bb.ustc.edu.cn` / `bb.ustc.edu.cn`
- 首页和作业区优先用 fetch 读取每门课的成绩列表，按唯一作业标题匹配；重名、草稿、成绩表缺项或无法识别的状态自动回退到单项查询，成绩列表不可用时也可回退
- 每次进入首页都重新核验作业列表与批量状态，缓存只显示带有「重新核验」提示的上次结果，不再整天跳过检查；回到后台超过一分钟的首页或从作业区后退时，也会重新核验
- 首页与作业区共享最近 5 分钟的逐项状态快照，进入作业区时先显示上次结果并后台核验，避免状态全部重新变成空白；打开单项作业、忽略或恢复作业会使相关统计失效
- 全局最多 6 个查询，单项慢查询最多占 3 个；超时覆盖响应正文读取，12 秒后取消该请求，临时故障重试一次，超时和 4xx 不反复等待
- 所有数据仅存于浏览器本地（localStorage），不与任何第三方通信
- 部分查询失败时仍显示已查到的待交数并标注待确认项，不误报「作业已交齐」、不缓存成当天的完整统计；首页可点击「重试未完成查询」重新确认
- 未完成时显示「至少 N 项待交」或查询提示，完整核验后才显示「暂无待交 · 刚核验」；空作业区和已忽略项目会单独说明。查询结束还会检查是否收到所有结果，漏回调不能变成成功的零计数
- 兼容 Blackboard 自带的 Prototype 1.7：不使用其覆盖的 `Array.from` 转换 `Set` 或调度任务。升级到 1.4.7 会丢弃旧版未经完整验证的统计，只保留作业区入口

## 本地开发与预览

安装 Node.js 后运行 `node dev/preview.mjs`，打开 <http://127.0.0.1:4173>，即可用虚构数据预览门户和作业区。无需学校账号或安装依赖；页面直接加载当前脚本，修改后刷新即可。详见 [预览说明与验证场景](dev/README.md)。

运行 `node --test dev/regression.test.mjs` 检查 BB 旧库兼容、任务完成判定、旧缓存迁移和状态共享。预览默认启用与真实 BB 相同的 `Array.from` 覆盖。
